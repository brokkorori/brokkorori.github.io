Privacy Policy

This Privacy Policy explains how the website “brokkorori Image Editing Tools” (hereinafter referred to as “the Site”) handles user information.

1. Information We Collect

The Site provides image editing tools (cropping, resizing, compression, conversion, rotation, PDF conversion, etc.). We do not store any uploaded images on our servers.

All processing is completed within the user’s browser (local environment), and no image data is sent to external servers.

2. Purpose of Using Personal Information

The Site does not collect or use personal information. All image data, input values, and editing operations are processed entirely within the browser and cannot be viewed by the Site administrators.

3. Providing Personal Information to Third Parties

The Site does not provide any personal information to third parties.

4. Access Analytics Tools

The Site may use access analytics tools (such as Google Analytics) to improve service quality. These tools collect anonymous data and do not include information that identifies individual users.

5. Handling of Image Data

Images uploaded by users are processed only within the browser and are not transmitted to servers. Closing the page or clicking the reset button will completely delete the image data.

6. Disclaimer

The Site is not responsible for any troubles or damages arising from the use of the Site. Please use the tools at your own discretion.

7. Changes to This Privacy Policy

This policy may be updated as needed. Any changes will take effect when posted on this page.
