オンライン画像編集ツール集（HEIC対応）

ブラウザだけで画像を変換・圧縮・リサイズ・PDF変換できる無料ツール集です。
iPhoneのHEIC画像にも対応。ドラッグ＆ドロップで、日常の画像処理をまとめて完了できます。

無料で使える インストール不要 ブラウザ内でローカル処理 スマホ対応
English version

目的から探す

「とにかくこの作業をしたい」という人向けに、よくある用途別におすすめツールをまとめました。

  • ・スマホ写真を軽くしたい → 画像圧縮ツール
  • ・HEICをJPGにしたい → 画像変換（HEIC対応）
  • ・ブログ用に画像サイズを揃えたい → 画像リサイズ
  • ・不要な部分を切り取りたい → 画像トリミング
  • ・写真の向きがおかしい → 画像回転
  • ・画像をPDFにまとめたい → PDF変換（画像→PDF）
  • ・PDFの中身を画像として取り出したい → PDF変換（PDF→画像）

人気ツールランキング

よく使われている定番ツールです。迷ったら、まずここから試してみてください。

  • 1位：画像圧縮ツール（ファイルサイズ削減に最適）
  • 2位：画像変換ツール（HEIC / WebP / PNG / JPEG対応）
  • 3位：画像リサイズツール（縦横比維持でサイズ変更）
  • 4位：PDF変換ツール（画像→PDF / PDF→画像）
  • 5位：画像トリミングツール（不要部分の切り出し）

画像編集ツール

PDF関連ツール

画像とPDFの相互変換に対応したツールです。書類の画像化や、画像のPDF化に便利です。

📄 PDF変換（画像→PDF / PDF→画像）
画像をPDFにまとめたり、PDFの各ページを画像として書き出せるツールです。
資料作成や書類の共有に役立ちます。
画像→PDF / PDF→PNG / 複数ページ対応

安全性と技術的な特徴

すべての画像処理はブラウザ内で完結します。
画像データは外部サーバーにアップロードされず、お使いのPC・スマホのローカル環境のみで処理されます。

機密性の高い書類や、個人情報を含む写真でも安心してご利用いただけます。
Windows・Mac・iPhone・Androidなど、主要な環境で同じように動作するよう設計されています。
