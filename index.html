English

このサイトでできること

このサイトは、ブラウザだけで画像を編集できる無料オンラインツールです。 画像の変換（JPEG / PNG / WebP / HEIC）、リサイズ、圧縮、トリミング、回転、PDF変換など、 日常的に必要な画像処理をまとめて行えます。 インストール不要で、ドラッグ＆ドロップするだけで簡単に使えます。

安全性について

画像はすべてブラウザ内で処理され、外部サーバーに送信されません。 機密性の高い画像や個人情報を含む写真でも安心してご利用いただけます。 Windows・Mac・iPhone・Androidなど、どの環境でも同じように動作します。

  • 🔄 画像変換（JPEG / PNG / WebP / HEIC）
    • iPhoneのHEIC画像にも対応。複数ファイルの一括変換が可能です。 ブログ・SNS・資料作成など幅広い用途に使えます。
  • 📏 画像リサイズ
    • 縦横比を維持したままサイズ変更できます。 Webサイトやサムネイル用の画像調整に便利です。
  • 📦 画像圧縮
    • 画質を保ちながらファイルサイズを小さくできます。 メール添付やWeb掲載用の軽量画像を簡単に作成できます。
  • ✂️ 画像トリミング
    • 不要な部分を切り抜いて保存できます。 アイコン作成や写真の一部切り出しに便利です。
  • 🔁 画像回転
    • 画像を90度・180度など自由に回転できます。 スマホで撮影した写真の向き調整に最適です。
  • 📄 PDF変換（画像→PDF / PDF→画像）
    • 画像をPDFに変換したり、PDFを画像に変換できます。 資料作成や書類の画像化に便利です。
