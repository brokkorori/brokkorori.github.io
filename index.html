オンライン画像編集ツール（HEIC対応）

ブラウザだけで画像を変換・リサイズ・圧縮できる無料ツールです。iPhoneのHEIC画像にも対応しています。

このサイトでできること

このサイトは、ブラウザだけで画像を編集できる無料オンラインツールです。 画像の変換（JPEG / PNG / WebP / HEIC）、リサイズ、圧縮、トリミング、回転、PDF変換など、 日常的に必要な画像処理をすべてまとめて行えます。 インストール不要で、ドラッグ＆ドロップするだけで簡単に使えます。

  • 画像変換（JPEG / PNG / WebP / HEIC）
    • iPhoneのHEIC画像にも対応。複数ファイルの一括変換が可能です。
  • 画像リサイズ
    • 縦横比を維持したままサイズ変更できます。
  • 画像圧縮
    • 画質を保ちながらファイルサイズを小さくできます。
  • 画像トリミング
    • 不要な部分を切り抜いて保存できます。
  • 画像回転
    • 画像を90度・180度など自由に回転できます。
  • PDF変換（画像→PDF / PDF→画像）
    • 画像をPDFに変換したり、PDFを画像に変換できます。
